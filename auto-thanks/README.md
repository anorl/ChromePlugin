# 自动打开并感谢（auto-thanks）

独立的 Chrome / Edge Manifest V3 扩展，不依赖本仓库的其他插件，图标为蓝底白色“谢”字。按设定的页码范围遍历种子列表，依次打开详情页、尝试点击“说谢谢”，再关闭详情页。

## 安装

1. 下载并保留 `auto-thanks` 文件夹。
2. 打开 `chrome://extensions/`，Edge 使用 `edge://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `auto-thanks` 文件夹。
4. 在安装扩展的同一浏览器配置中登录目标 PT 站点，并打开其 `torrents.php` 列表页。

更新代码后，重新加载该扩展。

## 配置与使用

点击工具栏中的扩展图标，填写以下内容：

| 配置 | 说明 |
| --- | --- |
| 列表页模板 | 完整列表页地址，必须含 `{page}` 占位符；运行时会替换为实际页码。 |
| 起始页 | 要处理的第一个 `page` 参数值，最小为 1。 |
| 结束页 | 要处理的最后一个 `page` 参数值，包含该页，不能小于起始页。 |

例如：

```text
https://example.com/torrents.php?cat=401&page={page}
```

配置为起始页 1、结束页 3 时，会依次访问 `page=1`、`page=2`、`page=3`。可以保留分类、排序等其他查询参数。模板地址决定实际访问的站点，请改为自己已登录的目标站点。

部分站点的第一页使用 `page=0`，当前界面不支持输入 0；这里的页码指 URL 参数值，不一定等于页面显示的页码。

填写后点击“保存”，保持目标站点的 `torrents.php` 列表页为当前标签页，再点击“开始”。点击“开始”时也会自动保存当前配置。

## 运行过程与面板

扩展会在当前列表标签页中逐页导航，收集 `details.php?id=…` 链接并去重，再逐个在后台标签页中处理详情。每个详情处理完毕后自动关闭，然后继续下一项。

面板显示运行状态、已打开详情数、感谢成功数、感谢失败数、跳过数、已处理分页数，以及当前分页和详情地址。

- **停止**：停止后续处理；正在加载或处理的详情页可能仍会完成并关闭。
- **清空日志**：清除已访问详情记录和统计。请先停止任务并等待当前详情处理结束，再清空日志。
- **再次开始**：从配置的起始页重新遍历，已记录的详情会跳过。失败的详情也会进入访问记录；清空日志后才能再次尝试，同时也会重新访问先前成功的条目。

配置和访问记录保存在 `chrome.storage.local`。关闭浏览器或重新加载扩展不会自动恢复中断的批处理；如果面板仍显示“运行中”，可先点击“停止”，再重新开始。

## 适配范围与限制

- 启动页面的路径必须以 `torrents.php` 结尾，详情链接需使用 `details.php?id=…` 形式。
- 当前使用通用按钮候选规则识别和触发感谢，网站布局、按钮结构及登录状态会影响结果，不能保证适配所有 PT 站点。
- “感谢成功”通过按钮状态和页面 DOM 变化判断，是客户端统计，不等于已经取得站点服务器的成功回执。
- 当前代码中的列表页加载等待上限为 15 秒，感谢结果等待上限为 4 秒。相关时间参数位于 `background.js` 顶部，界面没有间隔设置项。
- 插件使用当前浏览器的登录状态，不提供自动登录或验证码处理功能。

## 权限

| 权限 | 用途 |
| --- | --- |
| `tabs` | 导航列表页、打开和关闭处理用的详情标签页。 |
| `scripting` | 在页面读取详情链接并执行感谢按钮操作。 |
| `storage` | 在本地保存配置、访问记录和统计。 |
| HTTP / HTTPS 网站访问权限 | 适配用户配置的不同站点地址。 |
