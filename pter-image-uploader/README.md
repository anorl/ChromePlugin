# PTerClub 图片上传助手

Chrome Manifest V3 插件。右键点击网页图片，将原图上传至 https://s3.pterclub.net/，自动将 `[img]图片直链[/img]` 写入剪贴板。

上传文件名使用北京时间（Asia/Shanghai），格式为 `年月日_时分秒_毫秒_随机后缀.扩展名`，例如 `20261023_163025_123_a1b2c3d4.jpg`，降低连续上传时重名的概率。最终直链以图床返回的地址为准。

## 安装与使用

1. 在 Chrome 打开 `chrome://extensions/`，启用右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本 README 所在的 `pter-image-uploader` 文件夹。需要 Chrome 116 或更新版本。
3. 打开 https://s3.pterclub.net/ 并完成登录。登录必须在安装插件的同一 Chrome 配置文件中完成。
4. 在任意普通网页的图片上右键，点击「上传至 PTerClub 并复制 BBCode」。
5. 插件图标显示 `OK` 后即可粘贴。显示 `!` 时点击插件图标查看原因；上传成功但复制失败时，可在弹窗中再次复制，无需重新上传。

弹窗显示最近上传图片的缩略预览，保持原图比例，点击可打开原图。保留最近 5 次成功上传结果，在预览右侧直接展示，无翻页按钮，默认选中最近一次上传；点击时间可同步切换预览与 BBCode，并自动复制 BBCode。默认使用图床的 `private` 可见性；持有直链的人仍然可以访问图片。也可以在弹窗切换为公开上传。

## 上传方式与权限

- 依据站点当前 Chevereto 3.15 前端使用的协议，从首页读取当前会话的 `auth_token`，使用 `POST /json`、`action=upload`、`type=file` 上传文件。无需填写 API Key，也不保存密码或单独读取 Cookie。
- 图片先由插件读取为二进制文件，再上传，图床无需自行访问来源网站。登录状态由 Chrome 自动附带。
- HTTP/HTTPS 主机权限用于读取不同网站和 CDN 的原图，以及访问图床。插件没有常驻网页内容脚本，不自动扫描或上传图片。
- `contextMenus` 添加图片右键菜单，`offscreen` 和 `clipboardWrite` 用于后台复制，`storage` 在本机保存可见性和上传结果。没有第三方统计服务。
- `declarativeNetRequestWithHostAccess` 在读取当前原图时临时添加 `Referer`，兼容豆瓣等要求来源头的图片服务器。优先使用图片所在框架或网页的来源域名，缺失时使用图片自身域名，不附带页面路径或查询参数。规则仅匹配插件发起的当前图片 GET 请求，任务结束后删除，不修改普通网页请求。
- 使用 Chrome 官方推荐的 offscreen 剪贴板方式：https://developer.chrome.com/docs/extensions/reference/api/offscreen

## 限制与排查

- 支持 HTTP、HTTPS 和 `data:image/` 图片；暂不支持网页专属 `blob:` 临时地址、CSS 背景图片、浏览器内部页面及本地文件。
- 插件限制单张图片不超过 20 MiB；图床自身可能还有更低的大小或格式限制。不会转码或压缩图片。
- 某些来源网站的防盗链、验证码或特殊登录限制仍可能阻止原图读取。遇到 HTTP 403 等错误会明确提示，不会把错误页面作为图片上传。
- 登录过期或图床需要安全验证时，先打开图床处理，再重试。
- 上传连接中断、超时或响应异常时，图床可能已经收到图片。请先到图床检查，插件不会自动重试上传。
- 关闭 Chrome 或重新加载插件会中断尚未完成的任务；已收到成功响应的图片链接会先保存再尝试复制。多次右键点击按顺序处理。

在此目录执行 `npm test`。测试覆盖实际上传表单字段、成功/失败响应、原图读取与大小限制。真实账号上传和 Chrome 剪贴板仍需按上面的操作步骤验收。
