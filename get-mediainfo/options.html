获取mediainfo

在 PT 详情页点击“播放视频”打开本地 PotPlayer，或点击“获取mediainfo”读取并复制 MediaInfo。

安装与配置指南（首次使用请展开）
  1. 在 Chrome / Edge 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，加载下载的 get-mediainfo 文件夹。
  2. 安装 Python 3.10 或更新版本。安装后在 PowerShell 运行 python --version，确认命令可用且版本不低于 3.10；如安装器提供 Add Python to PATH 选项，可勾选它。
  3. 在文件资源管理器中打开你下载的插件文件夹，进入 native，双击 install.cmd。它会自动定位脚本目录、识别扩展 ID，并为当前用户注册本地助手，无需手填绝对路径或扩展 ID。
  4. 安装完成后点击本页“读取配置 / 检查连接”，检查下方预填的程序路径，填写自己的视频目录，选中一个默认目录后保存。程序安装位置不同时可直接修改路径。
  5. 刷新 PT 种子详情页，即可使用“获取mediainfo”和“播放视频”。移动插件文件夹后重新加载扩展并再次双击 native\install.cmd。

助手目前支持 Windows；只读取信息时配置 MediaInfo CLI 即可，播放视频时再配置 PotPlayer。卸载助手时，在 native 文件夹打开 PowerShell，运行 powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall。

视频目录

每行一个路径，在右侧选中默认目录。播放和读取信息只搜索该目录，修改后点击“保存配置”。
MediaInfo CLI 下载与配置
  1. 打开 MediaInfo 官方 Windows 下载页，选择与你的电脑架构对应的 CLI（Command Line Interface），不要选择 GUI 或 DLL。普通 Intel / AMD 64 位电脑选择 Intel 64 bit 的 CLI。
  2. 将下载的 ZIP 压缩包全部解压到一个固定目录。CLI 版解压即可使用，可以与图形界面版共存。
  3. 将解压后 MediaInfo.exe 的完整路径填入上方输入框，点击“保存配置”。要检查版本，可在 PowerShell 先输入 & 和一个空格，将 exe 文件拖入窗口，再加一个空格和 --Version 运行；正确版本会输出 MediaInfo Command line。
  4. 回到 PT 详情页点击“获取mediainfo”，再点“复制mediainfo”粘贴到发布页。需要站点隐藏标签时，保持“添加 [hide=mediainfo] 标签”勾选。
