# PT 种子认领助手

Chrome Manifest V3 扩展，图标为蓝底白色“认”字。当前适配 PTerClub 用户详情页的“当前做种”列表，并严格按以下顺序串行操作：

1. 点击一个“认领种子”；
2. 等待第一层“确认认领”弹窗并点击“确定”；
3. 等待第二层 AJAX 结果弹窗加载完成，再点击新的“确定”；
4. 页面刷新后按随机间隔继续下一个种子。

扩展只选择 `.claim-confirm` 且文本为“认领种子”的链接，不会点击“取消认领”。运行状态保存在 `chrome.storage.local`，因此站点自动刷新后仍可继续。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开已登录的 PTerClub 用户详情页，并定位到“当前做种”。
5. 点击工具栏中的扩展图标，确认间隔后点击“开始认领”。

首次安装后，如果目标页早已打开，请刷新该页面一次，让内容脚本生效。

## 安全行为

- 一次只处理一个种子；上一项未得到第二层结果前不会开始下一项。
- 站点返回失败、超时或弹窗结构不符合预期时自动暂停。
- 种子被其他用户抢先认领、条目失效等竞争失败会计入失败数并自动跳过，不会中断整轮任务。
- 余额/猫粮不足、达到上限、登录失效、权限或请求异常等阻断性错误仍会自动暂停。
- 暂时找不到按钮时会等待并重新加载，连续 3 次确认后才判定本轮完成。
- 用户可随时从扩展弹窗停止。
- 每次手动点击“开始认领”都会重置本轮完成/失败计数。
